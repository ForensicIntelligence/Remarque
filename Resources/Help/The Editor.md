## Write in the source pane

The native source editor supports macOS selection, spellcheck, Find and Replace, smart lists, bracket pairing, snippets, and formatting shortcuts. Settings → Editing controls these behaviors.

## Edit the rendered page

The rendered editor supports text selection, typing, headings, lists, tables, links, images, and formatting. The toolbar changes the selected content. Mermaid and LaTeX objects have source inspectors; changes there appear in Markdown immediately.

## Undo and handle external edits

Undo and Redo work across both panes. External file changes reload automatically when the document is clean. If you have edits, Remarque offers Keep Editing or Reload and captures a local version before replacement.
