File → Open Folder as Workspace grants access to a folder and indexes its Markdown files. The Workspace window provides file search, cross-file content search, and backlinks. Refresh the index after external changes.

Use [[Note Name]] to link to a note and [[Note Name|Display name]] to supply an alias. Command-click a rendered link to open it. Ambiguous matches are shown for selection rather than silently choosing a file.

The workspace is local. Security-scoped bookmarks retain your approved folder access across launches.
