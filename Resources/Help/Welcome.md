## Two panes, one document

| Do this | See this |
| --- | --- |
| Type Markdown in the left pane | The right pane updates as a formatted document. |
| Type or format text in the right pane | The Markdown source updates immediately. |
| Select a word, heading, cell, or diagram on the right | The left pane reveals the matching source, without taking keyboard focus. |
| Press **⌘Z** in either pane | Undo the latest edit from either editor. |

> [!TIP]
> **Synchronize scrolling** is on by default. Turn it off in [Settings → Preview](#settings:Preview) to browse each pane independently. Clicking rendered content still reveals its source.

## A toolbar for each kind of writing

| Tab | Use it for |
| --- | --- |
| **markdown** | Headings, emphasis, lists, links, and tables. |
| **Mermaid** | Diagram templates, source, layout, and supported visual editors. |
| **LaTeX** | Equations and seven palettes of mathematical symbols. |
