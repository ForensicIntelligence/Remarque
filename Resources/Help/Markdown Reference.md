Use # through ###### for headings; **bold**, *italic*, ~~strike~~, ==highlight==, `code`, ^superscript^, and ~subscript~ for inline styles.

Use - or 1. for lists, - [ ] and - [x] for tasks, > for quotes, and > [!NOTE] (also TIP, IMPORTANT, WARNING, CAUTION) for callouts. Tables use pipe-delimited rows and a --- alignment row.

Links use [label](url); images use ![alt](path). Wiki links use [[target|label]]. Footnotes use [^id] and a [^id]: definition. Definition lists put : definition on the line below a term. Details sections use <details> and <summary>.

Fenced code preserves literal text. A mermaid fence renders a diagram. $…$ and $$…$$ render math. YAML/TOML front matter is preserved. Unknown syntax remains available as source instead of being deleted.
