Create a blank document or choose Guided Tour, Technical Spec, Meeting Notes, Diagram Doc, or Product Plan. File → Show Start Window returns to these choices.

Type Markdown on the left or edit the rendered text on the right. Choose Editor, Editor + Preview, or Preview from the layout control. Toggle the outline for heading navigation.

Save the file before inserting linked images. Approve its media folder when the Grant Folder Access banner appears. Documents remain readable in other Markdown applications.
