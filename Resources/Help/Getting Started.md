Make a small document, try both editors, and save a Markdown file you can use anywhere.

## 1. Choose a starting point

Use **File → New**, or choose a template in the Start window. **File → Show Start Window** returns to the templates.

| Template | A useful starting point for |
| --- | --- |
| Blank Document | A fresh page |
| Guided Tour | Trying Remarque’s editing features |
| Technical Spec / Product Plan | Structured project documents |
| Meeting Notes | Decisions, discussion, and actions |
| Diagram Doc | A document built around diagrams |

## 2. Write a little, see the result

```example
# Project notes

A **clear plan** starts with a short list.

- [x] Create the document
- [ ] Review the draft
```

Click **Copy Markdown** above, then paste into the left source pane of a new document. Select a word on the right and try **Bold** in the **markdown** toolbar.

## 3. Arrange your workspace

```remarque-map
```

Choose **Editor**, **Editor + Preview**, or **Preview** from the layout control. Drag the splitters to resize panes. Use the outline to navigate headings.

## 4. Save and continue

Press **⌘S** to choose a filename and folder. The document remains ordinary UTF-8 Markdown.

> [!NOTE]
> Save before inserting linked images. If Remarque shows **Grant Folder Access**, approve the document’s media folder so the image can be read.
