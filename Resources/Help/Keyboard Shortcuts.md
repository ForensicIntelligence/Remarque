Keep the actions you use most close at hand. Symbols: **⌘ Command · ⇧ Shift · ⌥ Option · ⌃ Control**.

## Documents and history

| Action | Shortcut |
| --- | --- |
| New / Open / Save | ⌘N / ⌘O / ⌘S |
| Save As | ⇧⌘S |
| Save version | ⌃⌘S |
| Undo / Redo across both panes | ⌘Z / ⇧⌘Z |

## Write and insert

| Action | Shortcut |
| --- | --- |
| Bold / Italic / Link | ⌘B / ⌘I / ⌘K |
| Code block | ⌥⌘C |
| Equation | ⌃⌘E |
| Mermaid gallery | ⌥⌘M |
| Visual diagram editor | ⇧⌘M |
| Format document | ⌥⌘L |
