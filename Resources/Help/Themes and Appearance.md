## Choose a reading style

Settings → Appearance offers System, Paper, Midnight, and Graphite themes. Set the source font, source and preview sizes, line spacing, line numbers, current-line highlighting, and code syntax highlighting.

## Arrange the workspace

The source formatting ribbon includes smaller/larger text controls. Focus Mode hides window chrome; Typewriter Mode centers the active line while you write. Window splitters resize the outline, source, and rendered panes.
