Wrap Mermaid source in a fenced code block whose language is mermaid. Rendering is local and uses strict security. Scripts, remote loaders, and Mermaid click callbacks are not executed.

Select a diagram and choose Source to edit its Mermaid text live. Invalid source is retained with a visible error. Copy Source copies the original diagram language. SVG and PNG export use the rendered graphic.

Diagram metadata is stored in a Markdown HTML comment immediately before its fence. Width, height, alignment, title, and stable identity remain portable as ordinary text.
