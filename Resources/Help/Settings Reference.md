Open **Remarque → Settings…** to adjust the editor. Preferences are stored locally and reused on your next launch.

## Synchronize scrolling

In **Preview**, **Synchronize scrolling** is **on by default**. With it on, scrolling either pane follows the corresponding section in the other. Turn it off to compare distant passages independently.

[Open Preview settings →](#settings:Preview)

> [!NOTE]
> Selecting content in the rendered pane still reveals its Markdown even when scrolling synchronization is off. Editing and shared undo also remain connected.

## Find the right section

| Settings section | Controls |
| --- | --- |
| Appearance | Theme, fonts, sizes, spacing, line numbers, current line, code colors, status bar |
| Editing | Smart editing/headings, quotes/dashes, bracket pairs, paste, Live Editing, wrapping, typewriter, spellcheck, focus dimming, tool palette and ribbon |
| Preview | Live updates, debounce, synchronized scrolling, front matter visibility, external links |

| Export | Format, image storage, title/contents, paper/orientation, numbering, metadata, images, CSS, Mermaid source |

| Keyboard | Shortcut reference |
