## Your documents stay local

Remarque renders Markdown, Mermaid, and LaTeX locally. The editor has no runtime CDN dependency, telemetry, or account requirement. Document content is not sent to a server.

## Approve file access

The macOS sandbox limits access to documents and folders you approve. Media folders use security-scoped bookmarks. Recovery, history, settings, and scratchpad live in Remarque’s local application container.

## Keep a backup

External links open only after an explicit action. Embedded HTML is sanitized; remote media and executable diagram callbacks are blocked. Keep an independent backup of your Markdown files and source repository.
