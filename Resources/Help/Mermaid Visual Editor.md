## Build and connect

Select a flowchart, sequence diagram, or simple state diagram, then choose Visual Edit. Add nodes or participants, connect them, edit labels and arrow styles, and adjust supported shapes in the inspector.

## Arrange the canvas

Drag canvas nodes or use arrow keys to position them. Snap to Grid, Auto Layout, and Zoom help arrange the canvas. Sequence messages can be reordered where preserved control-flow syntax does not make reordering ambiguous.

## Apply safely

Apply writes one undoable source edit. Cancel preserves the original bytes. Unrecognized directives are retained verbatim; deletion is blocked when it would orphan a preserved reference. Composite states and other Mermaid families use the source editor. Canvas positions are saved as Mermaid comments.
