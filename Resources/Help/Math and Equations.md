Inline math uses $x^2$; display math uses a separate $$ block. The LaTeX toolbar opens the equation editor, changes inline/display mode, and edits selected equations.

Seven palettes provide Structures, Greek, Operators, Relations, Arrows, Symbols, and Functions. Choosing a symbol inserts TeX at the caret. Structures position the caret in the first argument slot.

The preview uses bundled MathJax. Existing equations update live in source. Inserting a new equation is confirmed with Insert; closing that dialog discards the uninserted draft.
