File → Export offers HTML, PDF, Word DOCX, RTF, Slides, EPUB, LaTeX, Remarque Bundle, and Embedded Markdown. Settings → Export controls paper size, orientation, title page, contents, numbering, images, and source inclusion.

PDF uses native pagination. Word builds document structure and includes rendered diagrams and equations as graphics. EPUB is an EPUB 3 package. Slides use first-level headings as slide boundaries. Print Document, Print Source, and Print Document and Source provide native print operations.

Exports snapshot the document revision. If it changes during preparation, Remarque asks you to export again. Missing or unsupported material is reported instead of being silently discarded. Imported Word, RTF, and PDF files become new unsaved Markdown documents; PDF import extracts selectable text and does not perform OCR.
