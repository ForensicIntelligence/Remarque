Microsoft Word (DOCX) • Real Word styles for headings, quotes, code, and tables • Bold, italic, inline code, and clickable hyperlinks • Diagrams embedded as images (with a graceful placeholder fallback) • Optional title page, table of contents, and page numbers • Opens cleanly in Word, Pages, and LibreOffice Writer Rich Text (RTF) A formatted RTF document that drops straight into any word processor or email — styled headings, lists, code, and links, with math and diagrams embedded as images, generated from the same typeset model as the preview. Slide deck (HTML) Turn a document into a self-contained slide deck: content splits into slides at each top-level heading, and the result is a single offline HTML file you navigate with the arrow keys — no framework or network needed. EPUB A valid EPUB 3 e-book split into chapters at each # heading, with a navigation document, embedded diagrams, and your local images packaged inside the book. LaTeX A standalone .tex document: headings, lists, tables, and formatting map to LaTeX, math passes through natively, and code uses a verbatim environment — ready to compile. Printing Print from the File menu or the keyboard. Print Document… (⌘P) prints the finished document, Print Source… the raw Markdown/Mermaid source, and Print Rendered & Source… both in one job — the rendered document followed by a labelled source listing. Diagrams are rendered by the bundled engine and a clean light theme is used for paper. Importing Word, RTF & PDF Going the other way, File ▸ Import Document… (⇧⌘I) converts an RTF, Word (.docx), or PDF file to Markdown and opens the result as a new document. Word packages are converted entirely in-app — equations, images, and numbered-list nesting all survive the trip, with images embedded so they always travel with the document.
