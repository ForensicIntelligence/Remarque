Version history Remarque keeps a local history of each saved document — automatically as you edit, plus File ▸ Save Version (⌃⌘S). Open File ▸ Version History… to see a diff against the current text and restore any snapshot — restoring first snapshots what you have now, so it can never lose work. Nothing leaves your Mac. Snippets Define reusable snippets in Settings ▸ Snippets. Type a snippet's trigger and press Tab to expand it (a $0 marker sets where the cursor lands), or insert one from the Command Palette. Presentation mode Choose View ▸ Start Presentation (⌥⌘Return) to present the document full-screen as slides — they break at each top-level heading. Navigate with the arrow keys or space; press Escape to exit.
