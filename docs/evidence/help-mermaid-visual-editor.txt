			35 text Mermaid: Visual Editor Build flowcharts, state and sequence diagrams by direct manipulation. Place your cursor in a Mermaid block and press ⇧⌘M (or click Visual Edit on its card) to open the visual editor. It has three parts: the generated source, an interactive canvas, and an inspector for the selected element. Editing a flowchart 1 Click Add Node to drop a new node, then rename it in the inspector. 2 Click Add Edge, then click a source node and a target node to connect them. 3 Drag nodes freely in any direction to reposition them; turn on Snap to Grid for tidy alignment. 4 Select a node to change its shape (rectangle, rounded, decision, circle). 5 Select an edge to set its label and style (arrow, line, dotted, thick). 6 Click Apply to write the generated Mermaid back into your document. Editing a state diagram stateDiagram-v2 diagrams open on the same canvas: states become nodes, transitions become labelled edges, and [*] start/end markers appear as small circles. Edits regenerate clean stateDiagram-v2 source — state "Label" as id aliases are preserved. Editing a sequence diagram • Add and rename participants in the inspector. • Add messages, choose sender and receiver, edit text, and pick an arrow style. • Reorder messages with the up/down controls. As you edit, the generated Mermaid updates live in the source panel. Lines the canvas doesn't edit — subgraphs, style/classDef/click/linkStyle directives, and exotic arrows — are preserved verbatim through Apply, and Remarque warns if an edit would orphan one of them. Choosing Cancel leaves your original source untouched.
